API Documentation

Extract AI conversations from ChatGPT, Claude & Gemini share links. Get fully structured JSON — messages, statistics, platform metadata — all in one shot.

🚀 Fastify  REST API
🎭 Playwright + Puppeteer  Dual Engine
⚡ Async  Job Queue (Redis + BullMQ)
🔒 API Key  Auth
🌍

Base URL

Server http://localhost:3100
API http://localhost:3100/api/v1
ℹ️ Replace localhost:3100 with your server IP or domain in production. Docker default port is also 3100.
⚡

Quick Start

1

Get your API Key

The API key is set via the API_KEY variable in your .env file. Default: ai-converter-secret-key-123

2

Copy a share link

Get a public share URL from ChatGPT, Claude, or Gemini. These are the links generated when you share a conversation.

3

Submit & poll your job

POST the URL with your API key — you instantly get a jobId. Then poll GET /extract/jobs/:jobId until status is done and the structured JSON is returned.

cURL — Hello World 
curl -X POST http://localhost:3100/api/v1/extract \
  -H "Content-Type: application/json" \
  -H "x-api-key: ai-converter-secret-key-123" \
  -d '{"url": "https://chatgpt.com/share/xxxxxx"}'
🔑

Authentication

All /api/v1/* endpoints require authentication via the x-api-key header. Public endpoints (/health, /version) do not require a key.

HeaderValueRequired
x-api-key your_api_key_here Required
Content-Type application/json Required
⚠️ Missing or invalid API key returns 401 Unauthorized. Do not expose your API key in frontend / client-side code.
401 Unauthorized Response
{
  "success": false,
  "error": {
    "code":    "UNAUTHORIZED",
    "message": "Missing x-api-key header."
  }
}

POST /api/v1/extract Extract Single Conversation ⌄

Submit a single AI conversation from a public share URL for extraction. The request is asynchronous: it returns a jobId immediately, and the actual extraction runs in a background worker (Redis + BullMQ). Poll GET /api/v1/extract/jobs/:jobId until the job is done.

⚠️ Extraction uses dual browser automation (Playwright + Puppeteer). Long conversations (hundreds of prompts) can take minutes — that's why the API is async, so no HTTP connection ever times out.

Request Headers

HeaderValueRequired
x-api-keyyour_api_keyRequired
Content-Typeapplication/jsonRequired

Request Body

FieldTypeRequiredDescription
url string (URL) Required Valid public share URL from ChatGPT, Claude, or Gemini
JSON — Request
{
  "url": "https://chatgpt.com/share/xxxxxx-example-id"
}

Response — 202 Accepted (instant)

JSON — Job Submitted
{
  "success":  true,
  "jobId":    "4f1e2a3b-9c8d-4e7f-8a6b-5c4d3e2f1a0b",
  "status":  "queued",
  "url":      "https://chatgpt.com/share/xxxxxx",
  "pollUrl":  "/api/v1/extract/jobs/4f1e2a3b-9c8d-4e7f-8a6b-5c4d3e2f1a0b"
}

Then poll the job (every 2–5s) until status becomes done — the full result is included in that response.

Code Examples

cURL
curl -X POST http://localhost:3100/api/v1/extract \
  -H "Content-Type: application/json" \
  -H "x-api-key: ai-converter-secret-key-123" \
  -d '{"url": "https://chatgpt.com/share/xxxxxx"}'
JavaScript (fetch)
const submit = await fetch('http://localhost:3100/api/v1/extract', {
  method:  'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key':    'ai-converter-secret-key-123'
  },
  body: JSON.stringify({ url: 'https://chatgpt.com/share/xxxxxx' })
});
const { jobId } = await submit.json();

// Poll until done
while (true) {
  const res = await fetch(`http://localhost:3100/api/v1/extract/jobs/${jobId}`, {
    headers: { 'x-api-key': 'ai-converter-secret-key-123' }
  });
  const data = await res.json();
  if (data.status === 'done')   { console.log(data.result); break; }
  if (data.status === 'failed') { throw new Error(data.error?.message); }
  await new Promise(r => setTimeout(r, 2000));
}
Python (requests)
import requests, time

resp = requests.post(
    "http://localhost:3100/api/v1/extract",
    headers={
        "Content-Type": "application/json",
        "x-api-key":    "ai-converter-secret-key-123"
    },
    json={"url": "https://claude.ai/share/xxxxxx"}
)
job_id = resp.json()["jobId"]

# Poll until done
while True:
    r = requests.get(
        f"http://localhost:3100/api/v1/extract/jobs/{job_id}",
        headers={"x-api-key": "ai-converter-secret-key-123"}
    ).json()
    if r["status"] == "done":
        for msg in r["result"]["messages"]:
            print(f"[{msg['role']}] {msg['content'][:80]}...")
        break
    time.sleep(2)
GET /api/v1/extract/jobs/:jobId Poll Job Status ⌄

Poll the status of an extraction job. Status transitions: queued → running → done (or failed). When done, the full extraction result is included under result.

ℹ️ Completed/failed jobs are retained in Redis for 1 hour, then cleaned up automatically (a 404 is returned after that).

Path Parameters

FieldTypeDescription
jobIdstring (UUID)Job id returned by POST /extract

Response — 200 OK

JSON — Running
{
  "success":    true,
  "jobId":      "4f1e2a3b-9c8d-4e7f-8a6b-5c4d3e2f1a0b",
  "status":     "running",
  "url":        "https://chatgpt.com/share/xxxxxx",
  "createdAt":  1754938800000,
  "startedAt":  1754938801200
}

Response — done (with result)

JSON — Done
{
  "success":  true,
  "jobId":    "4f1e2a3b-9c8d-4e7f-8a6b-5c4d3e2f1a0b",
  "status":  "done",
  "result": {
    "success":         true,
    "url":            "https://chatgpt.com/share/xxxxxx",
    "platform":      "chatgpt",
    "title":         "My AI Conversation",
    "messages":      [
      { "role": "user",      "content": "Hello!" },
      { "role": "assistant", "content": "Hi there!" }
    ],
    "promptCount":     1,
    "assistantCount":  1,
    "totalMessages":   2,
    "processingTime":  2430,
    "processingTimeLabel": "2s",
    "truncated":       false
  }
}

POST /api/v1/extract/batch Batch Extract — up to 10 URLs ⌄

Submit multiple conversations in a single request — each URL gets its own jobId (same async job-queue flow). Poll each job via GET /extract/jobs/:jobId.

ℹ️ Max 10 URLs per request. Failures are per-URL — one bad URL won't fail the whole batch.

Request Body

FieldTypeRequiredDescription
urls string[] Required Array of share URLs, max 10
JSON — Request
{
  "urls": [
    "https://chatgpt.com/share/xxxxxx",
    "https://claude.ai/share/yyyyyy",
    "https://gemini.google.com/share/zzzzzz"
  ]
}

Response — 202 Accepted (instant)

JSON — Batch Response
{
  "success": true,
  "total":   2,
  "jobs": [
    {
      "url":       "https://chatgpt.com/share/xxxxxx",
      "success":  true,
      "jobId":     "job-aaaa-bbbb-cccc",
      "status":    "queued",
      "pollUrl":  "/api/v1/extract/jobs/job-aaaa-bbbb-cccc"
    },
    {
      "url":       "https://claude.ai/share/yyyyyy",
      "success":  true,
      "jobId":     "job-dddd-eeee-ffff",
      "status":    "queued",
      "pollUrl":  "/api/v1/extract/jobs/job-dddd-eeee-ffff"
    }
  ]
}

Response Schema

All responses share a consistent structure. The success boolean always indicates request outcome.

Extract Response Fields

FieldTypeDescription
successbooleantrue on success
urlstringThe input URL that was extracted
platformstring"chatgpt" | "claude" | "gemini"
titlestringConversation title from the page
messagesMessage[]Array of message objects (see below)
promptCountnumberNumber of user messages
assistantCountnumberNumber of assistant replies
totalMessagesnumberTotal message count
summaryInputstringContent of the first user message
wordCountnumberTotal word count across all messages
characterCountnumberTotal character count across all messages
processingTimenumber (ms)Total processing time in milliseconds

Message Object

FieldTypeDescription
rolestring"user" or "assistant"
contentstringFull text content of the message
⚠️

Error Codes

Errors always return success: false with a structured error object containing a machine-readable code and a human-readable message.

JSON — Error Structure
{
  "success": false,
  "error": {
    "code":    "ERROR_CODE",
    "message": "Human-readable description."
  }
}
HTTP StatusError CodeWhen It Occurs
200 — Success. success: true
400 INVALID_REQUEST Body is malformed, url is missing or not a valid URL
400 UNSUPPORTED_PLATFORM URL domain doesn't match any supported AI platform
401 UNAUTHORIZED Missing or invalid x-api-key header
404 — API route not found
500 EXTRACTION_FAILED Browser automation error, page failed to load or parse
500 INTERNAL_SERVER_ERROR Unexpected server-side exception
